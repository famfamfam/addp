# Example corpus

Generated by `tools/generate_examples.py`. The manifest [cases.json](cases.json)
lists all valid, signed and intentionally invalid documents and expected rejection
stages. Every top-level message kind has at least one valid example.

All identities and external events are fictional. `.example` URLs need no hosting.
Registry checkpoints and fee payments are simulated. Fixture key seeds are publicly
derivable from the generator; never use them outside tests.

Valid structure does not establish external truth. Signature fixtures use real
Ed25519 signatures but authenticate only documentary statements. The negative
corpus distinguishes schema rejection from semantic rejection.

Read [the walkthrough](../docs/walkthrough.md) before interpreting the files as a
sequence. The feed upsert/deletion branch is separate from the initial purchase
snapshot, and after-sales events occur later than the quote evaluation time.
